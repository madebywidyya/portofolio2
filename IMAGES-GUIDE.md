# Widiya Portfolio — GitHub Pages

## Menambahkan foto
Masukkan foto ke folder:

- `images/profile/` → foto profil
- `images/gallery/` → foto-foto galeri
- `images/background/` → background
- `images/icons/` → ikon/gambar kecil

Contoh:
`images/profile/profile.jpg`

Gunakan nama file sederhana tanpa spasi, misalnya:
`profile.jpg`, `gallery-01.jpg`, `background.jpg`

## Di HTML
Contoh:
```html
<img src="images/profile/profile.jpg" alt="Widiya">
```

Setelah foto dimasukkan, commit/push folder ini ke GitHub dan aktifkan GitHub Pages.
